## Prompt constraints shared across the set

- Wide 16:9 editorial scientific illustration for a research website.
- Physically plausible visual hierarchy, restrained colour, and no embedded text.
- No axes, numerical data, logos, people, instrument branding, or watermarks.
- Avoid presenting the image as direct simulation or telescope output.

The original generated files remain in Codex's generated-image store; project copies are retained here so the website has no runtime dependency on that store.
