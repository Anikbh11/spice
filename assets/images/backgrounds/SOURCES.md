# SPICE xHI background sources

## Current xHI background

`spice-xhi-magenta-field.jpg` is derived from the project-team file
`/Users/abhagwat/Downloads/mp4/xHI_bursty.mp4`. It uses an intermediate
reionisation frame at approximately `z = 7.37`. The redshift stamp, title,
scale bar, and colour bar were removed with a wide crop before web compression.
The scientific colour field was retained; only opacity, saturation, contrast,
brightness, and the centre-reading mask are applied in CSS.

## Earlier continuous-field backgrounds

`spice-temperature-field.jpg` is derived from the project-team file
`temp3.mp4`. It uses the frame at 19 seconds (`z = 6.61`) and was cropped to a
16:10 field to remove the redshift stamp before web compression. The map is a
temperature rendering, not an xHI map. Its colour field was not repainted;
desaturation, contrast, and opacity are applied only in CSS.

`spice-xhi-field.jpg` is the earlier screenshot-derived prototype and is no
longer used by the site.

## Three-model alternative

The three background fragments in this directory are derived from the official
MPA animation **“Evolution of ionized hydrogen”**:

- Source page: https://www.mpa-garching.mpg.de/1086248/hl202310
- Source media: https://streaming-eu.mpg.de/de/institute/mpa/highlights/xhi_out.mp4
- Credit: © MPA
- Accessed: 2026-08-09

The local assets use a still near 20 seconds in the animation, where the bursty
and smooth models are at approximately `z = 7.07` and the hypernova model is at
approximately `z = 7.51`. The title, redshift label, scale bar, and colour bar
were cropped away because these fragments are decorative, not quantitative
figures. Near-black neutral regions were converted to transparency and the crop
edges were feathered. The underlying SPICE map colours were otherwise retained.

These assets should not be reused as figures or interpreted quantitatively. Link
to the original animation when presenting the maps as scientific evidence.
