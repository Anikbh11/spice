# SPICE simulation suite website

A static, GitHub Pages-compatible website for the SPICE radiation-hydrodynamics simulation suite.

## Local preview

Run any static file server from this directory and open `index.html`. No build step or package installation is required.

## Structure

- `index.html`: homepage, feedback overview, research projects, publications, and team
- `simulations.html`: detailed project description, physical model, numerical methods, feedback comparison, and limitations
- `publications.html`: primary and related literature
- `data.html`: planned paper-linked public data releases, documentation standards, and citation guidance
- `images.html`: scientific media archive
- `project-*.html`: five paper-led project-atlas pages, plus four unlinked legacy drafts retained locally
- `assets/css/site.css`: shared design system and responsive styles
- `assets/js/site.js`: progressive reveal and back-to-top behaviour
- `assets/images/papers/`: cited figure crops and their source manifest
- `assets/images/summaries/`: generated conceptual conclusion images and their disclosure manifest
- `photos/`: team portraits and their source manifest

## Required before publication

- Confirm reuse permission and preferred credit wording for all team portraits listed in `photos/SOURCES.md`.
- Confirm article licences and publisher credit requirements for the paper figures listed in `assets/images/papers/SOURCES.md`.
- Confirm the preferred reuse credit for the overview figures from Bhagwat et al. (2024).
- Add the final public contact address or contact workflow.
- Add movies only after source, caption, and reuse details are verified.
- Add data-release versions, licences, DOIs, and BibTeX when available.
- Review publication statuses and affiliations immediately before release.

The site is intentionally readable without JavaScript and does not submit data or load third-party scripts.
