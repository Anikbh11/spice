01 · Status

A release index before the files arrive.

Public releases are planned

This page reserves a stable home for SPICE data without implying that unreleased products are already available.

Each release will be connected to the project page and publication that define the analysis. Download buttons will appear only after the files, metadata, documentation, licence, and preferred citation have been checked by the team.

Nothing is downloadable yet.Dates and repository links will be added only when a release is ready. Until then, every entry below remains explicitly marked as planned.

02 · Release standard

What a useful scientific release should contain.

Data with enough context to reuse

Cite

Persistent record

Each deposited collection will list its version, persistent identifier, related paper, authors, and a copyable preferred citation.

Understand

Methods and metadata

Units, column definitions, selection criteria, feedback model, redshift, processing steps, and known limitations will travel with the files.

Reuse

Open, practical formats

Machine-readable tables and widely supported scientific formats will be preferred, with an explicit licence and compact example workflow where useful.

04 · Citation

Credit both the research and the released product.

How to cite future SPICE data

Each public collection will carry its own preferred data citation alongside the associated paper citation.

The release record will provide a copyable citation and BibTeX entry, version and DOI, creator list, licence, and direct link back to the relevant project. Until those records exist, please cite the paper used for the scientific result rather than this placeholder page.
